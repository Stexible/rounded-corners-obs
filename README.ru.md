# Rounded Corners для OBS Studio

[English version](README.md)

GPU-фильтр для OBS Studio, который скругляет углы любого видеоисточника (камера, захват окна, изображение, браузер, медиа). У каждого угла может быть свой радиус и своя форма кривой. Радиус задаётся относительно размера источника, поэтому результат выглядит одинаково на источниках любого разрешения.

## Возможности

- Альфа-маска со скруглёнными углами считается на GPU (пиксельный шейдер), нагрузки на CPU нет.
- Радиус в **процентах** от размера источника: 0% — острый угол, 100% — максимально возможное скругление (половина меньшей стороны).
- Ползунок **формы кривой**: от прямого диагонального среза через идеальную круговую дугу до почти квадратного угла.
- Настройки для каждого угла отдельно (левый верхний, правый верхний, правый нижний, левый нижний) или одно общее значение через **синхронное изменение**.
- Сглаженные края (антиалиасинг).
- Соседние углы не могут пересечься ни при каких радиусах.

## Требования

- OBS Studio 32 или новее (Windows, x64).

## Установка

### Без установщика (рекомендуется)

1. Закройте OBS Studio.
2. Скачайте последний `rounded-corners-windows-x64-*.zip` со страницы Releases.
3. Распакуйте архив в папку OBS так, чтобы файлы оказались здесь:

   ```
   obs-studio/obs-plugins/64bit/rounded-corners.dll
   obs-studio/data/obs-plugins/rounded-corners/effects/rounded-corners.effect
   obs-studio/data/obs-plugins/rounded-corners/locale/*.ini
   ```

   Папка OBS по умолчанию: `C:\Program Files\obs-studio`.

### Без прав администратора (для одного пользователя)

Положите файлы в `%APPDATA%\obs-studio\plugins\rounded-corners\`:

```
%APPDATA%\obs-studio\plugins\rounded-corners\bin\64bit\rounded-corners.dll
%APPDATA%\obs-studio\plugins\rounded-corners\data\effects\rounded-corners.effect
%APPDATA%\obs-studio\plugins\rounded-corners\data\locale\*.ini
```

## Использование

1. Нажмите правой кнопкой на источник в OBS и откройте **Фильтры**.
2. В разделе **Фильтры эффектов** нажмите **+** и добавьте **Rounded Corners**.
3. Настройте параметры.

| Параметр | Диапазон | Описание |
| --- | --- | --- |
| Синхронное изменение | вкл / выкл | Один радиус и одна форма для всех четырёх углов. |
| Радиус | 0 - 100 % | Размер угла относительно половины меньшей стороны источника. |
| Смещение центра дуги (форма) | -1 ... 1 | `-1` диагональный срез, `0` круговая дуга, `1` почти квадратный угол. |

Если синхронное изменение выключено, у каждого угла свои ползунки радиуса и формы.

> Подсказка: окна предпросмотра в OBS уменьшены. Мелкие радиусы проверяйте на реальном выводе или в проекторе в полном размере.

## Сборка из исходников

Проект основан на [obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate). Нужны Visual Studio 2022 и CMake.

```
cmake --preset windows-x64
cmake --build --preset windows-x64 --config RelWithDebInfo
```

Если ваши CMake-пресеты называются иначе, поправьте имена.

## Выпуск релиза

1. Соберите проект в `RelWithDebInfo` (или `Release`).
2. Разложите файлы по структуре из раздела «Установка».
3. Упакуйте папки `obs-plugins` и `data` в архив `rounded-corners-windows-x64-<версия>.zip`.
4. Создайте тег (`git tag v1.0.0 && git push --tags`) и прикрепите архив к GitHub Release.
